# Gourav — AI/ML Engineer Portfolio

A responsive, accessible, single-page portfolio focused on AI/ML engineering, research, and systems building.

## Highlights

- Premium dark visual system with responsive layouts
- Accessible navigation and mobile menu
- Sections for projects, engineering principles, research interests, skills, journey, and contact
- Honest project status labels without invented metrics or outcomes
- Reduced-motion support
- No framework or dependency required for the current static version

## Run locally

Because the current implementation is a static page, you can open `index.html` directly in a browser or serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
